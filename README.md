# linuxcncsetup

> [!WARNING]
> `setup.sh` is deprecated. It remains available as a compatibility wrapper,
> but new installations and updates should use `./tui/install.sh --run` or the
> installed `~/.local/bin/linuxcncsetup` TUI application.

The TUI includes **Install Remote Terminal**, where the machine display name,
local login account, LAN address, and HTTPS port are configured before the
bundled Ansible installer runs.
